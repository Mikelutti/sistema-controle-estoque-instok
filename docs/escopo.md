# Escopo do Projeto

## Objetivo

Sistema academico para gerenciamento e rastreabilidade de materiais
(controle de estoque), permitindo cadastrar produtos, controlar
entradas/saidas/transferencias entre setores e visualizar alertas de
estoque baixo ou sem estoque.

## Dentro do escopo (previsto)

- Login de usuarios
- Gerenciamento de usuarios, produtos, categorias e setores
- Entrada, saida, transferencia e inventario de estoque
- Historico de movimentacoes
- Alertas de estoque baixo / sem estoque
- Relatorios basicos
- Dashboard com visao geral

## Fora do escopo (nesta etapa)

- Integracoes externas (pagamentos, notas fiscais, etc)
- Aplicativo mobile
- Autenticacao avancada (ex: login social, 2FA)

> Este documento sera detalhado ao longo do desenvolvimento do projeto.
